1. Количество бит подсети

255.255.255.0

11111111.11111111.11111111.00000000 /24


255.255.255.224

11111111.11111111.11111111.11100000 /27

27-24=3

2. Количество созданных подсетей

2^3 = 8

3. Количество бит узлов в подсети

11111111.11111111.11111111.11100000 /27

k=32-27=5

4. Количество узлов в подсети

N=2^k-2=2^5-2=32-2=30

5. Сетевой адрес этой подсети

128 64 32 16 8 4 2 1

192.168.200.139 /27

11000000.10101000.11001000.100**01011**

11111111.11111111.11111111.111**00000**


11000000.10101000.11001000.100**00000** – адрес сети

192.168.200.128

6. IPv4-адрес первого узла в этой подсети

11000000.10101000.11001000.100**00001**

192.168.200.128 + 1 = 192.168.200.129

7. IPv4-адрес последнего узла в этой подсети

11000000.10101000.11001000.100**11110**

192.168.200.158

8. Широковещательный IPv4-адрес в этой подсети

11000000.10101000.11001000.100**11111**

192.168.200.159
